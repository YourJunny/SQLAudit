# SQLAudit

Change a SQLite, PostgreSQL or MySQL database without fear. Describe a change in plain English (or
write SQL, or edit a grid), see exactly which rows change, confirm it, and undo it any time.

## Download

**[Windows](https://github.com/YourJunny/SQLAudit/releases/latest/download/SQLAudit-Windows-Setup.exe)** ·
**[macOS](https://github.com/YourJunny/SQLAudit/releases/latest/download/SQLAudit-macOS.dmg)** (Apple silicon and Intel) ·
**[Linux](https://github.com/YourJunny/SQLAudit/releases/latest/download/SQLAudit-Linux.AppImage)**

Click the link for your computer and open the file. Nothing else to install.
SQLAudit updates itself: when a new version is out you'll see "Restart to update".

New to it? Open the **Practice** tab. It has a sample store database you can't
break and a checklist that walks you through every feature.

### The first time you open it

The builds aren't signed with a paid certificate yet, so your computer asks once:

- **Windows:** if you see "Windows protected your PC", click **More info**, then **Run anyway**.
- **macOS:** open the .dmg and drag SQLAudit to Applications. Open it; when macOS says it can't
  verify the app, click **Done**. Then go to **System Settings > Privacy & Security**, scroll down,
  click **Open Anyway** next to SQLAudit, and confirm. You only do this once.
- **Linux:** right-click the AppImage > Properties > allow running as a program (or `chmod +x`).
